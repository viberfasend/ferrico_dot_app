# Ferrico

A local-first bookmark manager. This glossary pins down the words we use for
the things a user collects, organizes, and acts on.

## Language

### Library

**Bookmark**:
A saved URL with a title, an optional note, at most one Folder, and any number of Tags.
_Avoid_: Item, link, entry

**Folder**:
A named, nestable container; a Bookmark lives in at most one.
_Avoid_: Collection, directory

**Inbox**:
The Bookmarks that are not in any Folder.
_Avoid_: Unsorted, uncategorized

**Tag**:
A named, colored label; a Bookmark can carry many.
_Avoid_: Label, category

**Selection**:
What the sidebar currently scopes the Bookmark list to — All, Inbox, Broken, Bin, one Folder, or one Tag.
_Avoid_: Filter, view, scope

### Keyboard (desktop)

**Shortcut**:
A key combination that triggers an action on desktop, shown wherever that action is offered.
_Avoid_: Hotkey, keybinding, accelerator

**Mod key**:
The platform's primary modifier — ⌘ on macOS, Ctrl on Linux and Windows. Shortcuts are defined in terms of it, never a literal ⌘ or Ctrl.
_Avoid_: Command key, control key (when meaning both)

**Shortcut sheet**:
The overlay listing every Shortcut, opened with `?` or from the header.
_Avoid_: Cheat sheet, keyboard help, shortcut list
